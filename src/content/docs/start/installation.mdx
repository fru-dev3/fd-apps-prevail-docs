Most people want the **desktop app**. It's a native, signed and notarized build with the engine bundled in — download, drag to Applications, launch. There's nothing else to set up.

You can also grab any version from the [releases page](https://github.com/fru-dev3/prevail-desktop/releases) or [prevail.sh](https://prevail.sh).

<Steps>

1. **Download** the `.dmg` (macOS) or `.exe` (Windows) above.

2. **Install.** On macOS, drag **Prevail.app** to `/Applications`. On Windows, run the installer.

3. **Launch.** Builds are notarized, so there's no Gatekeeper "damaged" warning and no right-click dance.

4. **Explore the demo.** The app opens in demo mode with a pre-populated household vault. Look around, then point it at your own folder when you're ready (Settings → Vault).

</Steps>

<Aside type="tip" title="Nothing to configure first">
The app bundles the Prevail engine, so it works on its own. Installing the CLIs (Claude, Codex, etc.) or adding an OpenRouter key just unlocks more models — see [Models & providers](/desktop/models/).
</Aside>

### Auto-update

The app updates itself. When a new release ships, Prevail downloads it in the background and offers to relaunch — no reinstalling. You can check manually in Settings → About.

## Requirements

- **macOS 13+ (Apple Silicon)** or **Windows 10/11 (x64)**.
- Optional: one or more of `claude`, `codex`, `agy`, `ollama` on your `PATH`, and/or an [OpenRouter](https://openrouter.ai) key. The bundled engine handles the rest.
- An existing vault, or just use the built-in demo — no setup required.

## Install the CLI engine

The same engine that powers the app is also a standalone CLI — a terminal cockpit, scriptable commands, a `--json` API, and the MCP server. Reach for it when you want automation or a headless box. See [The CLI & engine](/cli/overview/).

<Tabs syncKey="install">
  <TabItem label="curl | bash">
    ```bash
    curl -fsSL https://prevail.sh/install | bash
    ```

    The installer detects your platform, downloads the matching binary from the
    latest GitHub release, and places it on your `PATH` (typically
    `~/.local/bin/prevail`). Then:

    ```bash
    prevail        # launch the terminal cockpit
    prevail demo   # explore the synthetic demo vault first
    ```
  </TabItem>

  <TabItem label="Homebrew">
    ```bash
    brew tap fru-dev3/prevail-cli
    brew install prevail
    ```

    Upgrades come through `brew upgrade prevail` like any other formula.
  </TabItem>

  <TabItem label="From source">
    Requires [Bun](https://bun.sh) ≥ 1.3.

    ```bash
    git clone https://github.com/fru-dev3/prevail-cli
    cd prevail-cli
    bun install
    bun run build        # compiles dist/prevail
    ./dist/prevail
    ```

    Or run straight from source without compiling:

    ```bash
    bun run start        # equivalent to `prevail`
    bun run demo         # boot the synthetic demo vault
    ```
  </TabItem>
</Tabs>

### Verify a CLI install

```bash
prevail doctor          # checks your vault and which AI CLIs it can see
prevail doctor --debug  # also dumps the tail of ~/.prevail/debug.log
```

### Upgrading the CLI

<Tabs syncKey="install">
  <TabItem label="curl | bash">
    ```bash
    prevail upgrade            # self-update from the latest GitHub release
    prevail upgrade --check    # just report whether an update exists
    prevail upgrade --pre      # include prereleases
    ```
  </TabItem>
  <TabItem label="Homebrew">
    ```bash
    brew upgrade prevail
    ```
  </TabItem>
  <TabItem label="From source">
    ```bash
    cd prevail-cli && git pull && bun install && bun run build
    ```
  </TabItem>
</Tabs>

## Platform support

| Platform | Desktop app | CLI engine |
|---|---|---|
| macOS arm64 (Apple Silicon) | ✅ Signed & notarized | ✅ Native binary |
| macOS x86_64 (Intel) | — | ✅ Native binary |
| Windows x64 | ✅ Signed installer | ⚠️ Via WSL |
| Linux x86_64 / arm64 | — | ✅ Native binary |

See [Platform support](/reference/platform/) for details.

## What gets installed where

| Path | What it holds |
|---|---|
| The app (Applications / Program Files) | Prevail Desktop + the bundled engine |
| `~/.prevail/` | Machine-local state: config, secrets, connector auth, session DB |
| `<your vault>/` | Your domains, memory, logs, journals — the part you sync |

<Aside type="caution" title="Keep secrets out of sync">
`~/.prevail/` holds machine-local secrets (tokens, OAuth refresh tokens). If you sync your vault, sync the **vault folder only** and exclude `~/.prevail/`. See [Syncing your vault](/vault/sync/).
</Aside>
