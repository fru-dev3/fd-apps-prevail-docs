This is the 60-second tour of the **desktop app**. It assumes you've [installed Prevail](/start/installation/). (Prefer the terminal? See the [CLI quickstart](/cli/overview/).)

## 1. Launch into demo mode

Open Prevail. Every launch starts in **demo mode** with a pre-populated household vault — realistic domains, data, and chat history — so you can explore with zero risk before pointing it at your own life.

<figure>
  <img src="/img/desktop-home.png" alt="Prevail Desktop home screen — domain sidebar on the left, a model picker, and 'What should we work on?' with domain cards." loading="lazy" />
  <figcaption>The home screen — domains on the left, your models along the input bar, and a prompt asking what you want to work on.</figcaption>
</figure>

- **Left sidebar:** every life-domain, with pinned ones up top. `+ new domain` adds one.
- **Header tabs:** **Chat**, **Council**, **Benchmark**, plus **Insights**, **Usage**, **Preferences**, and **Back up**.
- **Input bar:** your prompt, a framework/lens picker, and the model selector.

## 2. Pick a domain and ask

<Steps>

1. **Click a domain** in the sidebar — say `wealth`. The chat is now grounded in that domain's real state and history.

2. **Pick a model** in the input bar — an installed CLI (Claude, Codex, Antigravity, Ollama) or any model via OpenRouter.

3. **Type a question** and press Enter:

   ```text
   should I sell or rent the condo?
   ```

</Steps>

The reply streams in live, grounded in everything that domain already knows about you.

## 3. Convene the council

Switch to the **Council** tab (or pick *Council* in the model selector) and ask the same question. Prevail fans it out to every available model in parallel, then a **chair** synthesizes one verdict — with a panel showing exactly where the panelists disagreed.

<Aside type="tip">
Disagreement is the point. When two strong models split on "sell" vs "rent," the *reason* they diverge is usually the real decision you need to make.
</Aside>

→ [How the council works](/council/overview/)

## 4. Watch it start to learn you

You don't have to do anything to make Prevail remember. The moment you send a message it's captured as an **intent** — a durable transcript — and distilled into that domain's memory (`_memory.md`), which is read back into your next chat. Ask a follow-up tomorrow and it already knows where you left off.

→ [Memory & self-learning](/desktop/memory/)

## 5. Make it yours

When you're ready to leave the demo:

<Steps>

1. **Settings → Vault** — point Prevail at your own folder (or let it create one).

2. **Import a starter pack** if you want a ready-made domain set for your situation (Family, Freelancer, High-Income, Creator, and more).

3. **Settings → Models** — install a CLI or add an OpenRouter key to unlock more models.

</Steps>

→ [Demo mode & starter packs](/desktop/demo/)
